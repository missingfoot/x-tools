# X Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Chrome extension for x.com that logs the video posts you see (Home, Bookmarks, Likes, profile Media tabs, including quoted videos) into a copyable History panel, and adds download buttons to post images and videos.

**Architecture:** Copy of `~/Projects/insta-tools` with the native helper, bridge, service worker and popup removed. Two content scripts: `content/history.js` (isolated world, `chrome.storage.local`) and `content/download.js` (page world, reads React fiber props). They share one thing through the DOM: `download.js` tags quoted post cards with `data-xt-post="user/id"` and `history.js` reads it.

**Tech Stack:** Plain JavaScript, Manifest V3, no build step. Tests: Node 24 `node:test` with Playwright (dev dependency only) driving Chromium with the unpacked extension against mock pages.

**Spec:** `docs/superpowers/specs/2026-10-15-x-tools-design.md`

## Global Constraints

- Plain JavaScript, no build step, no runtime dependencies. Playwright is a dev dependency for tests only.
- Manifest V3, name "X Tools", version 1.0.0, permissions `storage` and `unlimitedStorage` only, content scripts on `https://x.com/*`. No `key`, no popup, no background, no `action`.
- Identifiers: storage keys `xHistory.v1.home`, `.bookmarks`, `.likes`, `.profiles`, `xHistory.settings`, `xHistory.writer`; DOM host `#x-history`; button class `xdl-btn`; load guards `window.__xHistoryLoaded`, `window.__xDownloadLoaded`; quote tag attribute `data-xt-post`.
- Build UI with `createElement`, never `innerHTML`. Styles through constructed stylesheets.
- Comments explain why, not what. Every X-specific selector or pattern is a named constant at the top of its file with a comment on what was observed.
- User-facing text is plain and short. No em dashes.
- History logs video posts only (videos and GIFs). Link format `https://x.com/<user>/status/<id>`.
- Run all tests with `npm test` from the repo root (`/home/james/Projects/x-tools`).

## Review Focus

1. X recycles timeline cells: a quoted card reused for a different post must be re-tagged, not keep a stale `data-xt-post`. Test in Task 3.
2. The address bar username case differs from the post author's (`/nasa/media`, author `NASA`): still logged on Profiles and shown as the current profile. Test in Task 4.
3. The same post is in Bookmarks and Likes; clearing Likes must not break the Bookmarks link (authors are shared between tabs). Test in Task 4.
4. A video whose only variant is HLS (no MP4): the button goes red with a reason, nothing broken is saved. Test in Task 3.
5. A status page (`/<user>/status/<id>`) opened from a timeline: nothing is logged and the panel says so. Test in Task 4.

```js
// Test harness: loads the unpacked extension into Chromium and serves mock
// x.com pages that mirror the markup seen on the live site (15 Oct 2026).
import { chromium } from 'playwright';
import { mkdtemp, rm } from 'node:fs/promises';
import { tmpdir } from 'node:os';
import { join, dirname } from 'node:path';
import { fileURLToPath } from 'node:url';

export const ROOT = join(dirname(fileURLToPath(import.meta.url)), '..');

const CORS = { 'access-control-allow-origin': '*' };

// pages: { '/path': html }. Can be added to after launch.
export async function launch(pages, { viewport = { width: 1280, height: 800 } } = {}) {
  const profileDir = await mkdtemp(join(tmpdir(), 'x-tools-test-'));
  const context = await chromium.launchPersistentContext(profileDir, {
    channel: 'chromium',
    headless: true,
    viewport,
    acceptDownloads: true,
    args: [`--disable-extensions-except=${ROOT}`, `--load-extension=${ROOT}`],
  });
  const requests = [];
  await context.route('https://x.com/**', (route) => {
    const html = pages[new URL(route.request().url()).pathname];
    return route.fulfill(html === undefined
      ? { status: 404, body: '' }
      : { headers: { 'content-type': 'text/html' }, body: html });
  });
  await context.route('https://pbs.twimg.com/**', (route) => {
    requests.push(route.request().url());
    return route.fulfill({ headers: { 'content-type': 'image/jpeg', ...CORS }, body: 'jpeg' });
  });
  await context.route('https://video.twimg.com/**', (route) => {
    requests.push(route.request().url());
    return route.fulfill({ headers: { 'content-type': 'video/mp4', ...CORS }, body: 'mp4' });
  });
  const page = context.pages()[0] || await context.newPage();
  const close = async () => {
    await context.close();
    await rm(profileDir, { recursive: true, force: true });
  };
  return { context, page, requests, close };
}

export const DEFAULT_VARIANTS = [
  { content_type: 'application/x-mpegURL', url: 'https://video.twimg.com/ext_tw_video/1/pu/pl/list.m3u8' },
  { content_type: 'video/mp4', bitrate: 832000, url: 'https://video.twimg.com/ext_tw_video/1/pu/vid/640x360/low.mp4' },
  { content_type: 'video/mp4', bitrate: 2176000, url: 'https://video.twimg.com/ext_tw_video/1/pu/vid/1280x720/best.mp4' },
  { content_type: 'video/mp4', bitrate: 288000, url: 'https://video.twimg.com/ext_tw_video/1/pu/vid/480x270/lowest.mp4' },
];

// Outer post photos are wrapped in a /photo/N link. Quoted post photos are not.
function photoHtml(user, id, n, link) {
  const img = `<img alt="Image" src="https://pbs.twimg.com/media/P${id}x${n}?format=jpg&amp;name=small" style="position:absolute;inset:0;width:100%;height:100%">`;
  const inner = link ? `<a href="/${user}/status/${id}/photo/${n}" style="position:absolute;inset:0;display:block">${img}</a>` : img;
  return `<div data-testid="tweetPhoto" style="position:relative;width:500px;height:300px">${inner}</div>`;
}

// data-fake-variants is turned into React-like fiber props by fakeFibers().
function videoHtml(variants) {
  return `<div data-testid="videoComponent" data-fake-variants='${JSON.stringify(variants)}' style="position:relative;width:500px;height:280px">`
    + '<video style="display:block;width:500px;height:280px" poster="https://pbs.twimg.com/amplify_video_thumb/1/img/poster.jpg"></video></div>';
}

function mediaHtml({ user, id, video = false, photos = 0, link = true }) {
  let html = '';
  for (let n = 1; n <= photos; n++) html += photoHtml(user, id, n, link);
  if (video) html += videoHtml(video === true ? DEFAULT_VARIANTS : video);
  return html;
}

// A quoted post: a div[role=link] card with a <time> that is not a link.
function quoteHtml(q) {
  return `<div role="link" data-fake-tweet="${q.user}/${q.id}" style="display:block;width:520px;border:1px solid #888">`
    + `<div data-testid="UserAvatar-Container-${q.user}"></div><time datetime="2026-10-14T10:00:00.000Z">1d</time>`
    + mediaHtml({ ...q, link: false })
    + (q.quote ? quoteHtml(q.quote) : '')
    + '</div>';
}

export function post({ user, id, video = false, photos = 0, quote = null, height = 900 }) {
  return `<article data-testid="tweet" style="display:block;width:600px;height:${height}px;overflow:hidden;margin:0 0 100px">`
    + `<div><a href="/${user}">@${user}</a> <a href="/${user}/status/${id}"><time datetime="2026-10-15T10:00:00.000Z">1h</time></a></div>`
    + mediaHtml({ user, id, video, photos })
    + (quote ? quoteHtml(quote) : '')
    + '</article>';
}

export const doc = (...posts) =>
  `<!doctype html><html><head><meta charset="utf-8"></head><body style="margin:0"><main>${posts.join('')}</main></body></html>`;

// Mirrors what X keeps on its React fibers: the player's source.variants a few
// levels above the <video>, and the quoted tweet above a quote card (with the
// quoting tweet further up, so nearest-first lookups are exercised).
export async function fakeFibers(page) {
  await page.evaluate(() => {
    for (const el of document.querySelectorAll('[data-fake-variants]')) {
      el.__reactFiber$test = { memoizedProps: {}, return: { memoizedProps: { source: { variants: JSON.parse(el.dataset.fakeVariants) } } } };
    }
    for (const el of document.querySelectorAll('[data-fake-tweet]')) {
      const [user, id] = el.dataset.fakeTweet.split('/');
      const outer = el.closest('article').querySelector('a[href*="/status/"]').pathname.split('/');
      el.__reactFiber$test = {
        memoizedProps: { link: {} },
        return: {
          memoizedProps: { tweet: { id_str: id, user: { screen_name: user } } },
          return: { memoizedProps: { tweet: { id_str: outer[3], user: { screen_name: outer[1] } } } },
        },
      };
    }
  });
}

export async function until(fn, ok, { timeout = 5000 } = {}) {
  const end = Date.now() + timeout;
  let value = await fn();
  while (!ok(value) && Date.now() < end) {
    await new Promise((r) => setTimeout(r, 100));
    value = await fn();
  }
  return value;
}

const historyHost = (page) => page.locator('#x-history');

async function openTab(page, label) {
  const host = historyHost(page);
  if (await host.locator('.panel').isHidden()) await host.locator('.fab').click();
  await host.locator('.tab', { hasText: new RegExp(`^${label}$`) }).click();
  await host.locator('details:not([open]) > summary').evaluateAll((els) => els.forEach((s) => s.click()));
}

// Every link shown on a History tab, with all sections opened.
export async function loggedLinks(page, label) {
  await openTab(page, label);
  return historyHost(page).locator('.item a').allTextContents();
}

export async function sectionLabels(page, label) {
  await openTab(page, label);
  return historyHost(page).locator('summary .label').allTextContents();
}

export async function statusText(page) {
  const host = historyHost(page);
  if (await host.locator('.panel').isHidden()) await host.locator('.fab').click();
  return host.locator('.status').textContent();
}
```

```js
// X Tools: download buttons.
// Adds a download button to the top right corner of post images and videos
// on x.com. Runs in the page's own world, because the video files are only
// listed in X's React objects.
//
// Images are saved at their original size. Files are named after the post
// that owns the media: user_id[_n].ext.

(function () {
  'use strict';
  if (window.__xDownloadLoaded) return;
  window.__xDownloadLoaded = true;

  const BUTTON_CLASS = 'xdl-btn';
  // Rendered px. Avatars and link cards are already excluded by the selectors,
  // and a four photo grid shows images only about 145 px tall, so this only drops slivers.
  const MIN_SIZE = 100;
  // Every post on a timeline, a status page, Bookmarks and Likes (seen 15 Oct 2026).
  const ARTICLE_SELECTOR = 'article[data-testid="tweet"]';
  // Post photos. Video posters also sit inside tweetPhoto but load from
  // amplify_video_thumb or ext_tw_video_thumb, not /media/, so they do not match.
  const IMAGE_SELECTOR = '[data-testid="tweetPhoto"] img[src^="https://pbs.twimg.com/media/"]';
  const MEDIA_SELECTOR = IMAGE_SELECTOR;
  // A post's own link is the <a> around its <time>.
  const STATUS_PATH_RE = /^\/([A-Za-z0-9_]{1,15})\/status\/(\d{5,25})/;
  // Photos in a post with several are wrapped in /user/status/id/photo/N links.
  const PHOTO_PATH_RE = /\/photo\/(\d+)\/?$/;
  const SKIP_PATHS = /^\/(messages|i\/chat)(\/|$)/;
  const IMAGE_FORMATS = new Set(['jpg', 'png', 'webp', 'gif']);

  const ARROW = 'M12 4v11m0 0l-4.5-4.5M12 15l4.5-4.5M5 19h14';
  const CHECK = 'M5 12.5l4.5 4.5L19 7.5';
  const ICONS = { idle: ARROW, busy: ARROW, done: CHECK, error: 'M6 6l12 12M18 6L6 18' };

  const isVideo = (media) => media.tagName === 'VIDEO';

  // ---------- Finding media ----------

  function isPostMedia(media) {
    if (media.offsetWidth < MIN_SIZE || media.offsetHeight < MIN_SIZE) return false;
    return !!media.closest(ARTICLE_SELECTOR);
  }

  // The media is wrapped in a stack of same-sized divs (and, for photos, a
  // link to the photo viewer), with click-catching layers as siblings. The
  // button has to sit above all of them, so take the outermost positioned
  // wrapper that still matches the media's size.
  function frameFor(media) {
    const box = media.getBoundingClientRect();
    let frame = null;
    let node = media.parentElement;
    for (let depth = 0; node && depth < 12; depth++, node = node.parentElement) {
      if (node.tagName === 'ARTICLE') break;
      const b = node.getBoundingClientRect();
      if (Math.abs(b.width - box.width) > 2 || Math.abs(b.height - box.height) > 2) break;
      if (getComputedStyle(node).position !== 'static') frame = node;
    }
    // A video carries a poster image in the same frame. The video gets the button, not the poster.
    if (frame && !isVideo(media) && frame.querySelector('video')) return null;
    return frame;
  }

  function mediaIn(frame) {
    const all = [...frame.querySelectorAll(MEDIA_SELECTOR)].filter(isPostMedia);
    return all.find(isVideo) || all[0];
  }

  // Drop the button below any small control of X's that sits in the same corner.
  function place(btn, frame, media) {
    const box = frame.getBoundingClientRect();
    const target = { left: box.right - 44, right: box.right - 12, top: box.top + 12, bottom: box.top + 44 };
    const scope = frame.closest('article') || frame;
    const blocked = [...scope.querySelectorAll('[role="button"], button, a')].some((el) => {
      if (el === btn) return false;
      const r = el.getBoundingClientRect();
      if (!r.width || r.width > 100 || r.height > 100) return false; // skip full-size layers and photo links
      return r.left < target.right && r.right > target.left && r.top < target.bottom && r.bottom > target.top;
    });
    btn.style.top = blocked ? '52px' : '';
    // The tooltip shows what the last download did, until the next one.
    const label = btn.dataset.note || (isVideo(media) ? 'Download video' : 'Download image');
    if (btn.title !== label) {
      btn.title = label;
      btn.setAttribute('aria-label', label);
    }
  }

  function scan() {
    // Timeline cells are recycled as you scroll. Drop buttons whose media has gone.
    for (const btn of document.querySelectorAll(`.${BUTTON_CLASS}`)) {
      const media = mediaIn(btn.parentElement);
      if (media) place(btn, btn.parentElement, media);
      else btn.remove();
    }
    if (SKIP_PATHS.test(location.pathname)) return;
    for (const media of document.querySelectorAll(MEDIA_SELECTOR)) {
      if (!isPostMedia(media)) continue;
      const frame = frameFor(media);
      if (!frame || frame.querySelector(`:scope > .${BUTTON_CLASS}`)) continue;
      const btn = makeButton();
      frame.append(btn);
      place(btn, frame, media);
    }
  }

  // ---------- Sources ----------

  // X serves a smaller rendition by default. name=orig is the uploaded file.
  function imageSource(img) {
    const url = new URL(img.currentSrc || img.src);
    url.searchParams.set('name', 'orig');
    return url.href;
  }

  // ---------- File name ----------

  function ownPostOf(article) {
    for (const time of article.querySelectorAll('time')) {
      const a = time.closest('a');
      const m = a && article.contains(a) && STATUS_PATH_RE.exec(a.pathname);
      if (m) return { user: m[1], id: m[2] };
    }
    return null;
  }

  // The element whose post owns this media.
  function ownerRoot(media) {
    return media.closest(ARTICLE_SELECTOR);
  }

  function postOf(media) {
    const root = ownerRoot(media);
    const own = root && ownPostOf(root);
    if (own) return { ...own, root };
    // A status page shows the post in the address bar.
    const m = STATUS_PATH_RE.exec(location.pathname);
    return m ? { user: m[1], id: m[2], root: root || document.body } : null;
  }

  // 0 means no number: the post has only one media item.
  function indexOf(media, post) {
    const all = [...post.root.querySelectorAll(MEDIA_SELECTOR)].filter((m) => ownerRoot(m) === post.root);
    if (all.length < 2) return 0;
    const link = media.closest('a');
    const photo = link && PHOTO_PATH_RE.exec(link.pathname);
    return photo ? Number(photo[1]) : all.indexOf(media) + 1;
  }

  function extensionOf(url) {
    const u = new URL(url);
    const format = u.searchParams.get('format');
    if (IMAGE_FORMATS.has(format)) return format;
    return (/\.([a-z0-9]{3,4})$/i.exec(u.pathname) || [])[1] || 'jpg';
  }

  function fileName(media, url) {
    const post = postOf(media);
    const n = post ? indexOf(media, post) : 0;
    const base = post ? `${post.user}_${post.id}` : `x_${Date.now()}`;
    return `${base}${n ? `_${n}` : ''}.${extensionOf(url)}`;
  }

  // ---------- Downloading ----------

  // Returns the note for the button's tooltip.
  async function download(media) {
    const url = imageSource(media);
    // The CDN is a different origin, so a plain download link would just open
    // the file. Fetch it and save the bytes from a blob instead.
    const response = await fetch(url);
    if (!response.ok) throw new Error(`HTTP ${response.status}`);
    const blob = await response.blob();
    const name = fileName(media, url);
```

```js
      if (m) return { user: m[1], id: m[2] };

  // An article can hold two video posts: its own and the one it quotes. A
  // quote inside a quote is not logged. An untagged card is picked up on a
  // later tick, once content/download.js has tagged it.
  function videoPostsIn(article) {
    const cards = [...article.querySelectorAll(QUOTE_SELECTOR)].filter((c) => c.querySelector('time'));
    const top = cards.filter((c) => !cards.some((o) => o !== c && o.contains(c)));
    const videos = [...article.querySelectorAll(VIDEO_SELECTOR)];
    const posts = [];
```

```markdown
# X Tools

A Chrome extension for x.com with two tools:

- **History**: a floating panel that logs the video posts you see, so you can copy their links later. One tab per source: Home, Bookmarks, Likes and Profiles.
- **Download**: a button in the top right of post images and videos. Images are saved at their original size, videos and GIFs as the best MP4 X has for them.

Quoted posts count too: a video in a quoted post is logged and downloaded under the quoted post's own link.

## Install

1. Open `chrome://extensions` and turn on Developer mode.
2. Click Load unpacked and pick this folder.
3. Open or refresh x.com.

There is nothing else to install.

## Using it

### Download buttons

Hover a post image or video and click the round button in its top right corner.

- Green: saved. The tooltip shows the file name and, for videos, the resolution.
- Red: nothing saved. The tooltip says why.

Files are named `user_postid.ext`, with `_1`, `_2` and so on when a post has several images or videos. Buttons are not added in Messages.

### History

Click History at the bottom right of x.com.

| Tab | Page | What is logged |
| --- | --- | --- |
| Home | x.com/home | The video post in the middle of the screen as you scroll |
| Bookmarks | x.com/i/history | Every video post on the page |
| Likes | x.com/i/history/likes | Every video post on the page |
| Profiles | x.com/user/media | That user's video posts, in a section per user |

Only posts with a video or GIF are logged. Click a link to copy it, middle click to open it. Copy all and the per-section Copy buttons copy every link in view. Auto-scroll scrolls Bookmarks, Likes and Profiles to the end for you. Clear needs a second click and only clears the tab you are looking at.

Settings has a copy prefix (added to the start of every copied link) and Export and Import. History is kept by the extension, so removing the extension deletes it. Export first.

## How it works

- `content/history.js` runs in the extension's own world and keeps History in `chrome.storage.local`.
- `content/download.js` runs in the page's world, because the list of video files is only in X's React data. It also marks quoted posts with their own link so History can log them.

## Limitations

- Tested with the English interface.
- The best MP4 is usually 720p or 1080p. X's HLS stream is not used.
- History only logs while the tab is in view: X pauses loading in background tabs.

## Tests
```

npx playwright install chromium
npm test
```

MIT, see `LICENSE`.
```
